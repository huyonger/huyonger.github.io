The first paragraph is the excerpt shown under the title on the Blog page.

To publish: copy this file to `_posts/YYYY-MM-DD-short-title.md` (the date is
the post date; `short-title` becomes the URL, /blog/short-title/), edit the
front matter above, write the post in Markdown, then commit and push.
Files in `_drafts/` are never published.

## A section

Text, [links](https://example.com), images (put them in `images/blog/` and use
`![alt text](/images/blog/file.png)`), code blocks, and math all work.
